# SQL-запросы из коммерческой практики

Подборка SQL ad hoc-запросов, которые я писал для коммерческих задач в «Абсолюте». В публичном репозитории оставлены обезличенные примеры логики для метрик, продаж и качества лидов; рабочие схемы, клиентские данные и внутренние идентификаторы не публикуются.

Есть примеры на PostgreSQL и T-SQL: выборки, агрегации, CTE, оконные функции и расчёт метрик.

Основные файлы: [My complex queries](My%20complex%20queries) и [More requests](More%20requests). Это отдельные запросы и фрагменты из ad hoc-задач, а не один законченный аналитический проект. База данных не приложена; таблицы и поля нужно адаптировать под свою схему.
