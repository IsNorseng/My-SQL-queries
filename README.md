# Примеры SQL-запросов

Небольшая подборка запросов и фрагментов для аналитических задач: выборки, агрегации, CTE, оконные функции и расчёт метрик. Есть примеры для PostgreSQL и T-SQL.

Основные файлы: [My complex queries](My%20complex%20queries) и [More requests](More%20requests). Это отдельные примеры приёмов работы с данными, а не законченный аналитический проект. База данных не приложена; таблицы и поля нужно адаптировать под свою схему.
